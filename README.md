# Тренажёр «Н или НН» · 5 класс

Простой интерактивный тренажёр по русскому языку: правописание **Н** и **НН** в прилагательных, существительных и наречиях на -о/-е.

## Что внутри

- ~55 слов с разбором правила для каждого:
  - прилагательные с суффиксами -АН-, -ЯН-, -ИН- (одна Н);
  - прилагательные с суффиксами -ОНН-, -ЕНН- (НН);
  - случаи «основа на Н + суффикс -Н-» (НН);
  - исключения: *стеклянный, оловянный, деревянный, ветреный*;
  - существительные (*труженик, малинник, гостиная, странник*);
  - наречия на -о/-е (*туманно, искренне, ветрено*).
- Мгновенная обратная связь: подсветка правильного ответа + объяснение правила.
- Счёт верных, ошибок и текущей серии.
- Подсказка-конспект правил в свёрнутом блоке.
- Управление с клавиатуры: `Н` или `1` → Н, `2` → НН, `Enter`/`Space` → следующее слово.

## Как запустить локально

Никакой сборки не нужно — это статическая страница.

1. Скачайте репозиторий.
2. Откройте `index.html` двойным щелчком.

Или запустите простой сервер:

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

## Публикация (GitHub Pages)

После пуша в `main`:

1. В репозитории → **Settings → Pages**.
2. Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту страница будет доступна по адресу `https://<username>.github.io/<repo>/`.

## Структура

```
index.html   — разметка и подсказка с правилами
style.css    — стили (адаптивные, для телефона и компьютера)
words.js     — словарь слов с правилами
app.js       — логика тренажёра
```
